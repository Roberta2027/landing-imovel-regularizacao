Política de Privacidade

Atualizada em 25 de outubro de 2026

Esta política explica como a Schnaider Wiest Advocacia trata dados pessoais neste site e nas automações internas que o escritório usa para organizar o próprio trabalho. Ela segue a Lei Geral de Proteção de Dados (Lei 13.709/2018) e o dever de sigilo profissional da advocacia.

Quem é responsável

A controladora dos dados é Roberta Schnaider Wiest, advogada inscrita na OAB/SC sob o nº 65.344, titular da Schnaider Wiest Advocacia, com escritório em Joinville/SC. Para qualquer assunto de privacidade, escreva para advocacia@schnaiderwiest.com.

Este site

As páginas deste endereço são informativas. Não têm formulário, cadastro, cookies de rastreamento nem ferramentas de publicidade. O site fica hospedado no GitHub Pages e usa fontes do Google Fonts. Ao abrir uma página, seu navegador se conecta a esses serviços, que podem registrar dados técnicos de acesso, como endereço IP e tipo de navegador, conforme as políticas próprias deles. O escritório não recebe nem guarda esses registros.

Se você entrar em contato pelo WhatsApp ou por e-mail, os dados que você enviar serão usados só para responder ao seu contato e, se for o caso, para o atendimento jurídico.

Automação interna com o Google Drive

O escritório usa um aplicativo interno, chamado n8n-conteudos, que funciona no computador do próprio escritório. Ele não é oferecido ao público. A única conta Google que o usa é a do escritório.

Esse aplicativo pede acesso ao Google Drive da conta do escritório só para isto:

  • gravar, uma vez por dia, uma cópia de segurança (backup) dos dados do sistema de gestão de processos do escritório numa pasta do próprio Drive do escritório;
  • localizar essa pasta para salvar o arquivo no lugar certo.

O aplicativo não lê, não analisa e não altera outros arquivos do Drive. Ele não acessa contas de terceiros. Os dados obtidos pelas APIs do Google não são vendidos, compartilhados, usados para publicidade nem usados para treinar modelos de inteligência artificial. O uso desses dados segue a Política de Dados do Usuário dos Serviços de API do Google, inclusive os requisitos de Uso Limitado.

As credenciais de acesso ficam guardadas de forma criptografada no computador do escritório. O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.

Dados de clientes nos backups

Os backups contêm informações de processos e de contatos do escritório, protegidas pelo sigilo profissional. Eles ficam só no Google Drive da conta do escritório, com acesso restrito à advogada responsável, e servem apenas para garantir a continuidade do trabalho em caso de falha do sistema. Os arquivos são mantidos enquanto forem necessários para essa finalidade e para o cumprimento de obrigações legais e profissionais.

Seus direitos

Pela LGPD, você pode pedir confirmação de que tratamos seus dados, acesso, correção, anonimização, bloqueio ou eliminação de dados desnecessários, informação sobre compartilhamento e revogação do consentimento, quando for o caso. Basta escrever para advocacia@schnaiderwiest.com. Respondemos em até 15 dias. Você também pode reclamar à Autoridade Nacional de Proteção de Dados (ANPD).

Mudanças nesta política

Se esta política mudar, a nova versão será publicada nesta mesma página, com a data de atualização no topo.
